# v0.4.1 — 本地外观设置 / Local appearance settings

## 中文

- 在内嵌侧栏顶部“⋯ → 外观设置”修改浮窗文字、背景色、文字颜色和个人图标；稳定投递页面也有同样入口。
- 图片同步应用于选区浮窗、侧栏标题与工具栏。仅保存在当前浏览器本地，可一键恢复默认。
- 扩展管理页使用固定黑白结形图标。项目为非官方扩展，与 OpenAI 无隶属或背书关系。

安装：下载 chatgpt-sidebar-edge-chrome-v0.4.1.zip 并解压。在 edge://extensions/ 或 chrome://extensions/ 开启开发者模式，加载包含 manifest.json 的目录。

升级顺序：更新本地文件 → 重新加载扩展 → 刷新来源网页和 ChatGPT 页面 → 重新打开侧栏。无需卸载已有扩展。

内嵌模式可能受 ChatGPT 网站策略限制；可在“⋯ → 高级选项”切换稳定标签页投递。测试使用隔离浏览器和模拟页面，不代表真实网站登录验收。附件含 SHA-256 校验文件。

## English

Customize the popup label, colors and icon under ⋯ → 外观设置 (Appearance), also available in stable-delivery mode. Images apply to the popup, sidebar and toolbar; all settings stay locally in the current browser and can be reset. The extension-management icon is fixed. This is an unofficial extension with no OpenAI affiliation or endorsement.

Download and extract chatgpt-sidebar-edge-chrome-v0.4.1.zip. Enable Developer mode at edge://extensions/ or chrome://extensions/, then load the folder containing manifest.json.

Upgrade: replace local files → reload extension → refresh source and ChatGPT pages → reopen sidebar. No uninstall is required. Embedded mode depends on ChatGPT policies; switch to stable tab delivery in Advanced options if needed. Browser tests use isolated fixtures, not real-site login. A SHA-256 checksum accompanies the ZIP.
