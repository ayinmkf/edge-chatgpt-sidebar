# ChatGPT 侧边栏 · Edge 扩展 v0.3.2

默认直接在 Edge 侧栏内打开 ChatGPT。在普通网页选中文字并点击“问 ChatGPT”，即可投递到内嵌输入框。默认写入后自动发送，也可关闭自动发送，仅填入文字。

## 安装与更新

1. 在 Edge 打开 `edge://extensions/`，启用开发人员模式。
2. 已安装本项目时点击“重新加载”；首次安装时选择“加载解压的扩展”，指向 `D:\deepseek work\edge-chatgpt-sidebar`。
3. 关闭旧侧栏，再重新打开。顶部“设置”菜单底部应显示 v0.3.2。
4. **先重新加载扩展，再刷新来源网页和已有 ChatGPT 标签页**。更新前注入的旧脚本不会自动替换，否则可能提示“扩展已更新”。
5. 也可解压 `dist/edge-chatgpt-sidebar.zip`，加载解压后的目录；不要同时启用新旧两份扩展。

## 内嵌侧栏与设置

顶部“⋯”按钮展开设置，操作开关时无需离开内嵌侧栏：

| 设置 | 效果 |
| --- | --- |
| 写入后自动发送 | 开启时填入后尝试提交，关闭时等待手动发送 |
| 选中文本时显示“问 ChatGPT” | 控制普通网页上的选区浮窗 |
| 紧凑模式 | 隐藏底部状态条，顶部设置仍可使用 |
| 高级选项 → 稳定投递 | 改用本窗口的 ChatGPT 标签页，显示任务队列和诊断 |
| 高级选项 → 独立贴边窗口 | 打开或关闭独立 ChatGPT 窗口 |
| 高级选项 → 临时隐身 / UA 伪装 / 兼容写入 | 内嵌相关兼容设置；按需开启 |

**选中文字本身不会发送**，仍需点击浮窗或右键菜单。自动发送与浮窗等偏好持久保存，内嵌与稳定界面共享。工具栏扩展图标及 Ctrl+Shift+Y 可打开侧栏。

模式在当前浏览器会话中保留，后台休眠或重新打开侧栏不会改变选择。**浏览器结束会话后重新启动、扩展重新加载或更新后恢复内嵌模式**。Edge 后台运行时，仅关闭窗口可能并未结束浏览器会话。

内嵌启用时会开启用于嵌入的响应头规则。临时隐身和 UA 伪装默认关闭，浏览器重启后失效。临时隐身只是移除 iframe 导航请求的 Cookie / Authorization，不是完整的隐私隔离环境。“退出登录”会影响同一 Edge 配置中的 ChatGPT 标签页，操作前有确认。

内嵌仍可能受网站反嵌入策略、登录和网络环境限制。加载界面提供重试、在标签页打开及切换稳定投递入口；不会自动切换模式。

## 高级选项：稳定投递

从“设置 → 高级选项 → 切换到稳定投递（标签页）”进入。此时关闭内嵌响应头规则和隐身、UA 规则，选区内容改送到同一窗口最近使用的 `https://chatgpt.com/` 标签页，没有时新建。点击“返回内嵌侧栏”可恢复内嵌。

稳定投递保留原有串行队列：最多同时排队 20 条、保留 40 条记录，单条最多 20,000 字符。新任务保存入队时的自动发送设置。已有草稿不覆盖；页面尚未就绪时等待约 30 秒。明确尚未写入的失败可重试，投递后回执丢失则禁止直接重发，避免重复提交。

“已发送”表示页面出现新用户消息，或输入框清空并开始生成，不承诺服务器最终完成回答。侧栏提供原文、复制、目标标签页入口和任务诊断。

队列保存在 storage.session：后台休眠后保留，浏览器结束会话或扩展重载后清空。内嵌沿用单条待发送机制，不提供稳定模式的多任务队列；请等待当前任务完成再投递下一条。切换模式本身不重新投递上一条文本。

## 故障处理

- 浮窗提示扩展已更新：按“重新加载扩展 → 刷新来源网页”的顺序操作。
- 侧栏未自动打开：点击工具栏扩展图标；投递文字已经暂存时不必反复点击浮窗。
- 登录或人机验证：在 ChatGPT 页面完成后重试；无法内嵌时可手动切换稳定投递。
- 输入框已有草稿：先处理旧草稿，再投递。
- 已填入但未发送：检查自动发送设置，并在页面中手动确认。
- Edge 内部页面、扩展商店及 ChatGPT 页面本身不显示选区浮窗。

## 开发、测试与打包

纯 Manifest V3，无运行时依赖。测试需要 Node.js 22+ 与 Edge，可用 EDGE_PATH 指定浏览器路径。

```powershell
node tools/verify-queue.mjs
node tools/verify-stable.mjs
node tools/verify-fab.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1
```

完整链路测试使用独立临时 Edge 配置和本地模拟 ChatGPT 页面，覆盖默认内嵌、菜单开关、模式切换、稳定投递、编辑器适配及失败反馈。自动化不连接真实 ChatGPT 账号，真实网站的内嵌可用性须在登录环境验收。

测试截图可用 `--screenshot artifacts/panel.png` 保存到项目内。浏览器测试配置使用系统临时目录并在结束后清理。打包只包含源码、图标、说明和工具；不包含 Git、缓存、备份和旧安装包。覆盖 dist 安装包前保留旧包副本。

源码通过项目内 Git 管理；v0.3.1 基线保留在 main，本次修改在 feature/embedded-default。备份、产物和 dist 不纳入 Git，不向远程推送。

用户主动发送后，文本才交给 ChatGPT；无独立第三方服务或遥测。权限用于选区脚本、侧栏、会话存储、页面投递、嵌入规则与用户主动选择的 Cookie 清理。
